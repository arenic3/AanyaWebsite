# Instructions to maintain your site
---

It's pretty straightforward, the comments in the html file which begin with <!-- should help you for adding new images, shows etc...

However there are a few things you need to know

--- 
## Getting the repo on your laptop

for this you're gonna have to do some real nerdy shit, go on youtube and look up how to download git on mac and do what it tells you. with git you need to open your terminal app and your gonna type this in: `git clone https://github.com/whkstm9r6z-pixel/MyWebsite.git`

It will download to a directory that you can find by writing `pwd` in the terminal and then you can find it in finder and open it up in your code editor.

### Code editor
You're gonna need a code editor, the easiest one is probably VsCode which you can download from their website and set up in less than a minute (you really just need to sign in to your github account and thats it)

---

### Important stuff 

- Images, gifs need to be converted to the WebP or WebM format, you can find free converters online, and placed in the assets folder within the public folder.
- to update the site you need to commit the changes and push to github so that the remote repository matches your local one with all the new changes, you also need to update the version of the scripts which are highlighted in the HTML file as well. Youtube has dozens of 2 minute tutorials on how to do commit and push to github with vscode so that will be your best bet.

Note that for committing and pushing always write a comment or it will bug tf out.

That's all.
